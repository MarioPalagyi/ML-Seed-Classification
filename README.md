# ML-Seed-Classification

*NOTE:* Please see the final .html file for the results, as it is the knitted version of the .rmd file. It has instructions, descriptions and visualizations for clarity. I will provide a really short overview of the project here.

The goal of this project was to train an ML Classification algorithm, in this case Decision Trees that could differentiate between 3 types of different seeds.

3 types of Decision Trees had to be created in order to compare their accuracy against each other:
- a DT with default stopping criterion
- a DT without stopping criterion (Full Tree)
- a DT pruned from the Full Tree with optimal pruning

Furthermore, the exercise had to be repeated with only 3 measurements to test the accuracy of the model that way also.

In the final part "Random Forest and Adaboost - 04.02", I recreated the exercise, using ensemble models Random Forest and Adaboost and measured these models' performances.
